# เกษตรไทย Data Map

Dashboard แผนที่ประเทศไทยที่รวมข้อมูลจริงจาก 3 แหล่ง:

- `data.go.th` — ราคาสินค้าเกษตรระดับประเทศ
- `Open-Meteo` — อากาศ ความชื้นดิน ปริมาณฝน และ ET₀ ตามพิกัด
- `NASA POWER` — ค่าภูมิอากาศรายเดือนเฉลี่ยตามช่วงปีที่ผู้ใช้เลือก

## สิ่งที่เลือกและกดใช้งานได้จริง

- เลือกราคาสินค้าเกษตร 7 รายการจาก data.go.th
- เลือกจังหวัดครบ 77 จังหวัดจากเมนู หรือคลิกจังหวัดบนแผนที่
- เลือกช่วงภูมิอากาศย้อนหลัง 4 ช่วง โดยระบบส่งช่วงปีไปยัง NASA POWER ใหม่ทุกครั้ง
- เลือกแท็บภาพรวม ราคา อากาศและดิน หรือภูมิอากาศย้อนหลัง
- ซูม ย่อ และรีเซ็ตแผนที่
- กดอัปเดตข้อมูลทั้งสามแหล่งได้ทันที

ราคาจาก data.go.th เป็นราคาอ้างอิงระดับประเทศ ส่วนข้อมูลอากาศ ดิน และภูมิอากาศคำนวณจากพิกัดกึ่งกลางของจังหวัดที่เลือก จุดที่มีพิกัดอ้างอิงหลักจะใช้พิกัดเมือง และจังหวัดอื่นใช้จุดกึ่งกลางจากรูปทรงแผนที่

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:5173` หรือ URL ที่ Vite แสดงในหน้าต่างคำสั่ง

## ตรวจสอบและสร้างไฟล์ Production

```bash
npm run check
npm run build
npm run preview
```

โปรเจกต์ใช้ proxy ใน `vite.config.js` เพื่อเชื่อม API ทั้งสามแหล่ง ลดปัญหาการเรียกข้ามโดเมนจากเบราว์เซอร์ หากนำไปขึ้นระบบจริงควรย้าย proxy เหล่านี้ไปอยู่ที่ backend หรือ serverless functions ของผู้ให้บริการโฮสต์

เมื่อ API ตอบไม่ได้ หน้า Dashboard จะแสดงค่าตัวอย่างสำรองและแจ้งชื่อแหล่งข้อมูลที่มีปัญหา โดยไม่แสดงค่าตัวอย่างว่าเป็นข้อมูลสด
