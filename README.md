# เกษตรไทย Data Map

Dashboard แผนที่ประเทศไทยที่รวมข้อมูลจริงจาก 3 แหล่ง:

- `OAE Farm Plus` — ราคาที่เกษตรกรขายได้ ณ ไร่นา ทั้งแนวโน้มราคาและราคาเฉลี่ยรายจังหวัด
- `Open-Meteo` — อากาศ ความชื้นดิน ปริมาณฝน และ ET₀ ตามพิกัด
- `NASA POWER` — ค่าภูมิอากาศรายเดือนเฉลี่ยตามช่วงปีที่ผู้ใช้เลือก

## สิ่งที่เลือกและกดใช้งานได้จริง

- เลือกผลไม้ 20 ชนิดและสินค้าเกษตรอื่น 7 รายการที่ OAE Farm Plus มีข้อมูลปัจจุบัน
- ดูสีระดับราคาบนแผนที่ และชี้จังหวัดเพื่อดูราคาเฉลี่ย จำนวนรายงาน และหน่วยที่ OAE ใช้จริง
- เลือกจังหวัดครบ 77 จังหวัดจากเมนู หรือคลิกจังหวัดบนแผนที่
- เลือกช่วงภูมิอากาศย้อนหลัง 4 ช่วง โดยระบบส่งช่วงปีไปยัง NASA POWER ใหม่ทุกครั้ง
- เลือกแท็บภาพรวม ราคา อากาศและดิน หรือภูมิอากาศย้อนหลัง
- ซูม ย่อ และรีเซ็ตแผนที่
- กดอัปเดตข้อมูลทั้งสามแหล่งได้ทันที

ราคาทั้งหมดมาจากระบบราคา Farm Plus ของสำนักงานเศรษฐกิจการเกษตร (สศก.) โดยใช้ข้อกำหนดสินค้าและหน่วยเดียวกันในการเทียบจังหวัด จังหวัดที่ยังไม่มีรายงานจะแสดง “ไม่มีข้อมูล” และไม่สร้างราคาแทน ข้อมูลอากาศ ดิน และภูมิอากาศคำนวณจากพิกัดกึ่งกลางของจังหวัดที่เลือก จุดที่มีพิกัดอ้างอิงหลักจะใช้พิกัดเมือง และจังหวัดอื่นใช้จุดกึ่งกลางจากรูปทรงแผนที่

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:5173` หรือ URL ที่ Vite แสดงในหน้าต่างคำสั่ง

## ตรวจสอบและสร้างไฟล์ Production

```bash
npm run check
npm run build
npm run preview
```

โปรเจกต์ใช้ proxy ใน `vite.config.js` เพื่อเชื่อม API ระหว่างพัฒนา และใช้ Worker proxy เมื่อเผยแพร่บน Sites เพื่อลดปัญหาการเรียกข้ามโดเมนจากเบราว์เซอร์

เมื่อ API ราคาตอบไม่ได้ หน้า Dashboard จะแสดงว่าไม่พบข้อมูลและแจ้งชื่อแหล่งที่เชื่อมต่อไม่สำเร็จ โดยไม่สร้างราคาสำรองให้ดูเหมือนข้อมูลสด
